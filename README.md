# ⚡ ShopDunk E-Commerce Backend API (.NET & MongoDB)

![.NET](https://img.shields.io/badge/.NET-8.0-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![C#](https://img.shields.io/badge/C%23-12.0-239120?style=for-the-badge&logo=csharp&logoColor=white)
![MongoDB](https://img.shields.io/badge/MongoDB-6.0+-47A248?style=for-the-badge&logo=mongodb&logoColor=white)

Backend Web API chuyên nghiệp cho ứng dụng thương mại điện tử **ShopDunk Store**, thiết kế theo kiến trúc Clean Architecture với **ASP.NET Core 8** và **MongoDB**.

---

## ✨ Tính Năng Nổi Bật

- 🗄️ **NoSQL Database:** Lưu trữ thông tin sản phẩm có cấu trúc linh hoạt (biến thể màu sắc, dung lượng RAM/SSD) trên MongoDB.
- 🔑 **Authentication & Authorization:** JWT Authentication, phân quyền Admin và Customer.
- 📦 **Order Processing:** Xử lý quy trình đơn hàng, trạng thái vận chuyển và thanh toán.

```bash
git clone https://github.com/nguyenhuynhdt37/shopdunk-backend-dotnet.git
cd shopdunk-backend-dotnet
dotnet restore
dotnet run
```
